# UD01 - Árboles y Grafos

Autor: Inés

Tres ejercicios de consola en Java con estructuras de datos dinámicas.

## Ejercicios

**01 · Árbol de letras** (`Ejercicio01_ArbolLetras`)
Árbol binario de letras. El usuario escribe una letra y el programa muestra el camino desde la raíz (letras visitadas y direcciones L/R). Usa búsqueda en profundidad (DFS) y muestra el árbol por niveles. Si la letra no existe, lo indica.

**02 · Listín telefónico** (`Ejercicio02_ListinTelefonico`)
Listín de contactos en un árbol de búsqueda binaria ordenado por apellidos y nombre. Permite altas, bajas, modificaciones y búsquedas (por teléfono, por nombre, por prefijo y por rango). El teléfono es único y se busca rápido con un `HashMap`.

**03 · Planificador de rutas** (`Ejercicio03_PlanificadorRutas`)
Grafo dirigido y ponderado de una ciudad con transporte a pie, bici, bus y metro. Calcula la ruta más rápida con Dijkstra y permite evitar la bici, minimizar transbordos y tener en cuenta la hora punta.
